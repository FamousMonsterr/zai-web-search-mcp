# Code of Conduct

## Our pledge

Everyone participating in this project — maintainers, contributors, users,
and AI agents acting on someone's behalf — is expected to keep interactions
respectful and constructive.

## Standards

- Be kind and assume good faith.
- Critique code, not people.
- Stay on topic; keep issues and PRs about this project.
- Do not post secrets or personal data (API keys, tokens, private paths).
- Accept that maintainers may reject or close contributions.

## Enforcement

Abusive, harassing, or secret-leaking content will be removed, and repeat
offenders may be blocked from the repository. Report problems by opening a
private security advisory (see [SECURITY.md](SECURITY.md)) for security
matters, or by contacting the maintainer via the repository owner profile
(<https://github.com/FamousMonsterr>).
